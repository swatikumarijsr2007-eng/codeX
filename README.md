# codeX-crm

A self-hosted omnichannel CRM MVP for hackathons.

## Phase 1 delivered
- Monorepo structure for frontend and backend
- Docker Compose stack for frontend, backend, PostgreSQL, and MinIO
- Prisma schema and seed setup for RBAC and CRM entities
- Example environment variables
- Base TypeScript app scaffolding

## Run locally

```bash
docker compose up --build
```

Follow-up phases will add the API routes and UI components after approval.
